# Placeholder photography

Stand-in photographs for content slots that have no real image yet. They are
bundled locally so pages never depend on a third-party image host at runtime.
`src/lib/placeholder-image.ts` maps slots to these files.

These are **not final art**. Replace them by uploading real photography in
Admin → Media and setting it in Site content, on each project, and in the
gallery. Files here only need to change if the fallback itself should look
different.
